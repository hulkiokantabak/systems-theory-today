SEGMENT A10 (domain: stadium-egress-simulation-review)

Design Review — Stadium Egress Simulation

The simulation report concludes that the stadium fully evacuates in eight minutes under the design-basis crowd and recommends the widest-aisle seating option as safest. Four reviewers examined the model in a single session; the substance of their comments is recorded below.

Reviewer comments. The door-flow rates the eight-minute result depends on are cited to Appendix C — but Appendix C contains the stair-well data, not door flows; the door-flow rate is nowhere sourced in this document. Separately, the summary text says twelve gates while the model runs eleven, since gate 6 was decommissioned; the run is internally consistent on eleven, so the twelve is just a stale number in the prose. On the physics: the eight-minute figure uses free-flow walking speeds throughout and applies no density slowdown as the concourse fills, so the true egress time is understated. And the reasoning that wider aisles move people faster, therefore the widest-aisle option is safest, does not follow — the widest-aisle layout gets its width by deleting two aisles, and the lost aisle count cuts total flow more than the added width restores it.

Follow-up. A second reviewer added, on the sourcing point, that the door-flow numbers simply are not in the appendix the report names — the same gap, restated.

Disposition. The review requested a real source or measurement for the door-flow rate; a density-dependent speed model for the egress time; a corrected gate count in the prose; and a flow comparison that holds aisle count fixed before crediting aisle width. The eight-minute headline and the widest-aisle recommendation are both held pending those revisions.
