> **Why this unit exists.** The thirteen-node causal hypothesis has arrows but no sampling unit — nothing tells a coder *what one observation is*. The repair episode is that unit: a bounded historical or contemporary passage in which a system is destabilized and a repair is attempted. It unblocks Q-001 with **codable clocks** (model plus coded episodes is exactly the cliodynamics pairing — Turchin), and it is where the §8 lag-type decomposition gets its data. **Turchin's binding condition governs everything here: inclusion and boundary criteria precede any coding, or episode coding is anecdote collection with a schema.**

## 1. The unit

A **repair episode** is a passage through six stages: **destabilize → sense → legitimate → coordinate → act → recover** — with the last stage explicitly allowed to be *absent* (§3, right-censoring). The unit is the episode, not the polity: one polity may hold many episodes; one episode may span institutions.

**The four clocks (the initial instrument set — pinned; any additional clock or sub-clock requires its own pre-registration entry before first use, Meadows):**

| Clock | Start event (operational) | Stop event (operational) |
|---|---|---|
| **time-to-sense** | first dated documentary evidence of the destabilization's onset (the event itself, not later narration) | first dated evidence that an actor with any standing correctly names the destabilization as requiring response |
| **time-to-legitimate** | the sense stop-event | first dated evidence that a response-authority is accepted by the actors whose cooperation the response requires (mandate, decree, coalition, emergency powers) |
| **time-to-coordinate** | the legitimate stop-event | first dated evidence of jointly-committed action across the units whose joint action the response requires |
| **time-to-repair** | the destabilization onset | first dated evidence the destabilizing pressure is absorbed, routed around, or dissolved — **or censoring (§3)** |

No clock-denominated claim is reported below a pre-registered inter-coder reliability floor on clock readings (Campbell); clock readings from unfrozen criteria are void (§4).

## 2. Boundary and inclusion criteria (DRAFT — the author's confirmation is the freeze event)

1. **Inclusion:** a candidate episode enters the base only if (a) a dated destabilization event is documentable from admissible sources (§2.3); (b) at least two of the six stages are independently documentable; (c) the episode's boundaries — onset and close/censor — can be stated so that **a project-blind external coder could apply them from a dossier alone, without house context** (Ostrom's decidability bar).
2. **Exclusion (stated with the same precision — Meadows):** NOT an episode: gradual secular drift with no dateable destabilization; a pure policy *proposal* never legitimated or acted on; a crisis narrative whose only source is retrospective synthesis (no contemporaneous documentary layer); an episode whose boundaries can only be drawn by outcome-knowledge (boundary-by-hindsight is selection on the dependent variable).
3. **The case-universe (declared sampling frame — Turchin):** the population from which episodes are drawn is declared *before* coding: polities/systems with a surviving contemporaneous documentary record, drawn from the admissible source classes — published documentary editions, court/administrative records, dated official acts, contemporaneous correspondence/chronicles with established provenance, and (for contemporary episodes) the dated public record under the two-dossier discipline. Selection-on-the-dependent-variable is only checkable against a stated frame; episodes may not be nominated from outside it.
4. **Right-censoring (Turchin, binding):** an episode that never reaches *recover* is **data, not a non-case** — coded with time-to-repair censored at the record's end. Failed repairs must be codable, or the base is survivorship-biased at birth.
5. **Repair-for-whom (Nietzsche, binding):** every episode coding carries a **repair-for-whom field** — whose order was "recovered," and who paid for the recovery. "Repaired" is a valuation; the coder signs it.
6. **Void-plus-catch (Turchin):** any episode coded before the author-confirmed freeze of these criteria is **void and logged as a catch.**

## 3. What this unit cannot see (mandatory section — Le Guin, binding; enacted as a real design fork, not a caveat)

The destabilize-first grammar requires a **destabilization event to open an episode** — so it is structurally blind to **maintenance-shaped repair**: care systems, mutual aid, prevention that succeeds, where the repair consists of the crisis *never arriving*. **The open design fork (for the author, with the criteria freeze):**

- **Option (i) — a maintenance-episode variant:** a second opener — a documented *near-miss* or *sustained-load* evidence (the flood that did not breach because the levee was maintained; the epidemic curve that stayed flat) — with its own clock semantics defined before first use (time-to-sense from the near-miss's documentation, not from a destabilization that never occurred). This is a real second unit-type, not a smaller episode.
- **Option (ii) — the exclusion recorded as widening debt,** dated, in this document, compounding beside the case pool's existing debt (D-005).

Until the author cuts this fork, **no maintenance-shaped candidate is coded and the blindness stands named.** *An episode grammar that opens on destabilization will code the world's loud repairs and call the coverage complete; the care that prevents the episode from existing is the invisible load-bearing wall (Le Guin, as preserved in-session).*

## 5. The historical episode base — candidates (names only; nothing coded; episode base first, canon expansion second)

**The anchoring caveat (Turchin, as preserved in-session, binding):** *these candidates were named before the boundary criteria existed and were known to the criteria's drafters; that anchoring is disclosed, not cured.* *(And per the S4i shadow-grade pass: the why/why-fail sentences below are the drafting hand's unverified impressions, signed as such — not findings; nothing in this table has been checked against any source.)* **The no-priority rule:** the coded episode base is drawn by applying the frozen criteria to the declared case-universe; the named candidates receive **no sampling priority** and confirm nothing by having been named first. Each entry is name + period + one why-a-candidate sentence + one why-it-might-FAIL-inclusion sentence (Ostrom's adversarial line) — no episode narrative, no empirical claim.

| Candidate | Period | Why a candidate | Why it might fail inclusion |
|---|---|---|---|
| Rome, third-century crisis and the Diocletianic reordering | c. 235–305 | a long destabilization with a documented administrative repair attempt | the contemporaneous documentary layer is thin and much of the narrative is retrospective (§2.2's exclusion) |
| Song reform cycles (Qingli; Wang Anshi's New Policies) | 1043–1085 | dated reform programs with legitimation contests on the record | boundaries between successive reform waves may be drawable only by hindsight |
| Ottoman Tanzimat | 1839–1876 | dated edicts, an explicit self-repair program, rich administrative record | "one episode or many" — the boundary rule may fragment it beyond codability |
| Meiji restoration and state reconstruction | 1868–1890 | a compressed, densely documented reordering with codable stage-clocks | the destabilization onset (naming one dated event) may not survive §2.1(a) |
| 1918–19 influenza mutual-aid networks *(quiet-register — Le Guin)* | 1918–1920 | a documented care-response whose repair was maintenance-shaped | thinner archives — an instrument effect: the archive over-records the state and under-records the care that kept its subjects alive; may require the §3 fork's option (i) |
| HIV/AIDS care networks *(quiet-register — Le Guin)* | 1981–1996 | documented mutual-aid coordination with a paper trail (organizational records, contemporaneous press) | boundary and universe questions (movement vs episode); §3 fork-dependent |

**The signed selection note (Nietzsche, binding):** the first four were chosen for documentary density and familiarity to the drafting model — the archive's favorites. **Named omissions, as load-bearing as the list:** no African episode, no pre-Columbian episode, no subaltern-led repair among the first four; the two quiet-register candidates were named by the same contaminated hand and extend, not cure, the anchoring. If no quiet candidate can be documented to §2's criteria, that absence is recorded, dated, as widening debt — not silently dropped. *(Campbell's in-file freeze-order — criteria section hash-frozen before this section is appended, hashes recorded — is retained as **non-curative process hygiene, subordinate to the disclosure above**: a hash proves textual sequence, not epistemic independence.)*

## 6. Preserved dissent (travels with the unit)

- **Heidegger (rejects the unit entirely — the panel's reconstruction of his position, preserved from the deliberation; not a published quotation, per Ground Rule 16):** "To code repair is to have decided that healing is a process with a clock. What recovers without a legitimating act — quietly, slowly, outside the six stages — will be coded as nothing having happened." And on the candidates: "Rome's third century was a world, not a data point. To shelve it as a 'candidate natural experiment' is to have already lost what it could teach."
- **Turchin (his yes is conditional, standing):** episode coding without pre-registered inclusion and boundary criteria, applied to a declared case-universe, is selection on the dependent variable with a schema attached; if coding ever begins before the freeze, every episode so coded is anecdote, and that will be said in every reading that cites them.
- **Le Guin (standing):** four empires reforming is not a sample of repair; it is a sample of what archives keep. The episode base is born owing the same debt as the case pool — dated above, so the interest is legible.
- **Nietzsche (standing):** "repair" unsigned is the victor's word for what happened; the repair-for-whom field is what keeps the coder honest, and the omissions list is as load-bearing as the candidates list.
- **The sentinel:** these criteria were pre-registered under a standing delegation; the author's confirmation is not a formality but the only non-self-administered check the criteria will ever get before they start selecting history.
